# Party QOL

Bannerlord quality-of-life mod for party management (v1.4.8).

## Features

1. **Absorb via dialogue** — talk to an owned companion/clan war party leader and absorb hero, troops, prisoners, horses, and inventory into the main party with no capacity gate. Party must be outside an army.
2. **Party screen left selector** — dropdown under the left pane name (Dismiss + owned clan war parties). Right pane stays on the main party for v1. Open path supports arbitrary both sides for later expansion.
3. **Troop sort** — saved multi-key orders (Type / Tier / Level / Culture / Name / Count) with per-key asc/desc; Tier then Name are implicit tiebreaks when not selected. Independent of the TroopSort mod.

## Out of scope (v1)

- Unowned / vassal lord parties
- Right-pane party dropdown
- Mid-army absorb
- Fine-tuned multi-key config like TroopSort's XML presets
